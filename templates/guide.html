Expense Tracker User Guide

This reference guide explains how to use the expense tracker efficiently for daily personal or household financial management.

Back to dashboard

1. Add a new expense

  • Use the form at the top of the dashboard.
  • Enter a title, amount, category, and date.
  • Check the recurring option for repeat expenses such as rent or subscriptions.

2. Review and filter records

  • Use search to find an expense by name.
  • Filter by category or month to review trends.
  • Use the summary section to compare spending across categories.

3. Track budget and seasonal spend

  • Set a monthly budget from the dashboard.
  • Check remaining budget after each expense is added.
  • Use seasonal totals to compare spending across different periods of the year.

4. History and admin access

  • View the full expense history from the history page.
  • Admins can review all activity and user roles from the admin panel.
  • All updates are tracked in the database for audit and reporting.
